# LiteFS 故障排查

> 本文档帮助您诊断和解决 LiteFS 使用中的常见问题

## 问题诊断流程

1. 检查应用日志，查找异常堆栈
2. 检查配置文件是否正确
3. 检查存储路径是否有写权限
4. 检查数据库连接是否正常
5. 检查网络连接是否正常

## 常见问题

### 问题 1: 启动报错找不到数据库

**症状**:
- 应用启动失败
- 日志显示数据库连接错误

**原因**:
- `storage.jdbc-url` 配置错误
- 数据库服务未启动

**解决方案**:
1. 检查 `storage.jdbc-url` 配置是否正确
2. 确保 H2 或 MySQL 服务正常运行
3. H2 模式会自动创建数据库，检查路径权限

### 问题 2: 文件上传失败

**症状**:
- 上传文件时报错
- 日志显示存储异常

**原因**:
- 存储路径无写权限
- 磁盘空间不足

**解决方案**:
1. 检查 `storage.path` 目录权限
2. 检查磁盘空间是否充足
3. 检查文件大小是否超过限制

### 问题 3: 分布式节点无法通信

**症状**:
- 跨节点访问文件失败
- 副本复制不工作

**原因**:
- `remote.enabled` 未设置为 `true`
- 节点间网络不通
- 注册中心配置错误

**解决方案**:
1. 确认 `litefs.remote.enabled=true`
2. 检查节点间网络连通性
3. 检查注册中心配置



### 问题 4: 缓存数据不一致

**症状**:
- 不同节点读取到不同的元数据

**原因**:
- 分布式模式下使用了本地缓存

**解决方案**:
- 分布式模式必须使用 Redis 缓存
- `cache.type=local` 在分布式模式下会被自动禁用
