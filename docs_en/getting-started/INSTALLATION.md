# LiteFS Installation and Configuration

> This document details LiteFS installation steps and configuration methods

## Prerequisites

- JDK 17+
- Maven 3.6+
- Spring Boot 3.x project

## Installation Steps

### 1. Add Maven Dependency

```xml
<dependency>
    <groupId>io.github.fangyudev</groupId>
    <artifactId>litefs-spring-boot-starter</artifactId>
    <version>1.0.0</version>
</dependency>
```

### 2. Configuration File

See [Configuration Reference](../user-guide/CONFIGURATION.md) for complete configuration documentation.

### 3. Verify Installation

After starting the application, access the file upload interface to verify proper functionality.
